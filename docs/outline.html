STREET CONCEPT APP: BUILD OUTLINE

One flow, one project file. A location goes in; existing conditions, priced alternatives, renderings and branded sheets come out, then run through markup review to approval. Modeled on Southern California standards. Placeholders mark every screen still to build.

STANDARDS REGISTRY

One versioned table drives widths, markings, colors and checks. Each rule carries its source so CA MUTCD, Caltrans, agency direction and F&P convention stay separate.

SourceFeeds
CA MUTCD (current revision)Markings, colors, signs, stop bar placement
Caltrans HDM, DIBs (Class IV, complex bikeways)Lane and bikeway widths, buffers
Caltrans Standard PlansPavement marking details, unit cost items
SPPWC Greenbook standard plansCurb, gutter, ramp, local construction details
LADOT / LA Complete Streets Design Guide, BOE S-plansCity of LA overrides
LA County DPW, other agency standardsAgency override layer
PROWAG, CBC 11BPedestrian access route checks
LA Metro bus stop guidanceStops, bus lanes, layovers
F&P convention5 ft stop bar offset, green bike lanes, red bus lanes with BUS LANE text

Precedence: agency comments, then agency standard, then state, then F&P convention.

STACK AND BUILD PHASES

  • Front end: static site (Vite + plain TS or React), SVG section editor, pdf-lib for sheets.
  • Engine: existing skill scripts as a Python package; run as a small API (FastAPI) or in-browser through Pyodide.
  • Data: unit costs and standards as versioned CSV/JSON in the repo; assets as SVG library.
  • Fonts: Albert Sans bundled (OFL). Gill Sans needs a license before any distributed build.
  • Hosting: internal F&P host for work use; public build later for Esquina with non-F&P data.
